# Automation viewer demonstration

Recorded from the Linux/Kubernetes hardware test deployment on 2026-10-23,
using a Galaxy A55 (Android 16) and an iPhone 14 Plus (iOS 27.0.1).
The operator navigated STF manually with the interface set to English.
A separate automation account retained both reservations while Appium scrolled
Settings on the physical devices.

Both clips show opening an Automated device without taking control, the
view-only banner and disabled interaction controls. These are real interface
captures. Only leading/trailing waits were trimmed; playback retains recorded
speed. GIFs are 1100 px wide at 10 fps, without audio. Browser tabs, address bar
and bookmarks are outside the captured area.
